# aesthetic-encounter
Not another image-recognition tool. When a piece of art, architecture, or design stops you in your tracks, Aesthetic Encounter helps you understand it, articulate why it moved you, and distill it into a note for Obsidian or NotebookLM. Honest about what it can't identify. Grows an aesthetic profile as you use it.
# 审美偶遇 · Aesthetic Encounter

> 把眼睛被惊艳的那一下，变成能留下来、会长大的东西。

这**不是一个识图工具**。识别只是入口。它真正想做的是：当你在旅行或生活中偶遇一件让你眼前一亮的艺术品 / 建筑 / 设计 / 风景，帮你**驻足**——看懂它的背景与风格，说出你自己为什么被打动，把这份感受连进你个人的审美脉络，最后沉淀成一篇能进 [Obsidian](https://obsidian.md) / [NotebookLM](https://notebooklm.google) 的笔记。

用得越久，它越懂你被什么吸引。你的审美指纹会自己浮现出来。

---

## ✨ 它会做什么

- **诚实识别**：背景、风格、可能的作者与灵感来源——并明确区分「确证 / 风格归属 / 我的推测」，绝不为了显得博学而编造作者。
- **接住你的第一反应**：先和你对焦「是这几处在打动你吗」，你指哪点就往哪深挖，而不是甩给你一篇通用百科。
- **把惊艳转化为成长**：它让你想起什么、能内化什么、有什么招能借到你自己的创作里、和这个时代/地点/情绪产生了什么共振。
- **指给你下一站**：同一条审美母题，在哪个城市、哪种文明里会再遇见。
- **养出你的审美画像**：每篇笔记附一段「画像更新」，越积越厚，慢慢照出你自己的偏好脉络——也会偶尔温和地推你看一件舒适区之外的。

## 🚀 怎么用

### 方式一：当作可移植 Prompt（任何模型都行）

打开 [`SKILL.md`](./SKILL.md)，复制「**给使用者**」分隔线**以下**的指令体，粘进 Claude / Gemini / ChatGPT / DeepSeek 任意对话框，然后发一张照片或描述一个瞬间即可。

> 纯文本形态下，照片 EXIF/GPS 读取、画像文件自动存取会退化为手动——你自己说地点、自己把「画像更新」复制进文件保存。

### 方式二：当作 Claude Skill（更丝滑）

把整个文件夹作为一个 skill 安装到支持 skills 的 Claude 环境。这一版可以读照片 EXIF、自动读写画像文件、联网核实归属。

### 想先看看效果？

[`examples/`](./examples) 里有：
- [`示例-偶遇笔记.md`](./examples/示例-偶遇笔记.md) —— 一篇真实形态的输出（京都龙安寺石庭），让你一眼看懂笔记长什么样。
- [`审美画像-模板.md`](./examples/审美画像-模板.md) —— 复制它做你自己的画像起点。

> **关于配图**：纯对话形态下，模型无法把你发的照片打包进 `.md`。笔记顶部会保留一行 `![[ ]]` 占位符——把照片存进 Obsidian 库、填上文件名，图就显示出来了。能读写文件的环境会自动完成这步。

## 🧭 设计原则（为什么这样做）

| 原则 | 说明 |
|---|---|
| **接住第一反应 > 展示博学** | 笔记围着你被击中的那一下生长，不是通用艺术史百科。 |
| **慢一拍是特性** | 默认先对焦再成文——偶遇审美的价值在驻足。 |
| **但控制权永远在你手里** | 任何时候说「直接成文」立刻出稿；它也会主动察觉你不耐烦，自动收口。 |
| **诚实优于自信** | 认不出就说认不出，绝不编作者名。 |
| **镜子也是窗户** | 既反映你已有的偏好，也偶尔（以邀请而非评判的口吻）推你出舒适区。 |
| **内核与外壳分离** | 同一颗心脏，可套纯文本 / Claude Skill / 未来 App 三种壳。 |

## 🗺️ 路线图

**v1（当前）**：单次偶遇闭环 · 照片为主 · 维护画像 · Obsidian-ready 输出 · 跨平台纯文本可用。

**v2+（计划中）**：
- NotebookLM 叙述体双输出
- 视频抽帧分析（v1 仅支持「你挑一帧 + 文字补动态感受」）
- 完整文明地图 / 跨文明朝圣路线
- 众包审美地图（许多人的偶遇沉淀进同一张人类审美震颤地图）
- App：拍照即记 · GPS 自动补全 · 画像可视化 · 云同步
